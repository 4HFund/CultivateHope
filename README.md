# Cultivate Hope — Liberia

Initial responsive landing page for the emerging Cultivate Hope pilot initiative connected with Free Methodist World Missions. Designed for GitHub Pages.

## Publish
Go to Settings → Pages → Deploy from a branch → main / (root) → Save. The expected URL is https://4hfund.github.io/CultivateHope/ once Pages is enabled.
